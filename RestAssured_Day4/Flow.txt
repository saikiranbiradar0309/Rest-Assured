7. Open Postman
	--> Enter Application URL (POST) : http://localhost:8189/auth/signin
	--> Body --> Raw --> 
	    {
  			"email": "admin1@gmail.com",
  			"password": "admin123"
		}
		
	--> Check what is the status code you will get (You should get 201)


8. Lets store Request Payload 
	--> src/test/resources
	--> New Package --> Payload
	--> Create File --> AdminLoginPayload.json

		}



9. Now lets add Categorys
	--> http://localhost:8189/category
