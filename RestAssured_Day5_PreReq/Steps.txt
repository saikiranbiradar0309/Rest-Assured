Step 8: Create a Folder inside OAuth2 Collection (Name:  Access Token APIs)

        a. Add Request --> Name (Generate Access Token Using Password Grant Type - We Re-Authenticate Authentication Server)

        b. POST --> http://localhost:9080/oauth2/token --> Body --> x-www-form-urlencoded

            Key                     value                   
            grant_type              password
            client_id               employee_client
            client_secret           employee_secret
            username                Sai
            password                Sai123
            scope                   read write


            SEND


            const responseBody = pm.response.json();
            pm.globals.set("accessToken", responseBody.accessToken);
            pm.globals.set("refreshToken", responseBody.refreshToken);


Step 9: refresh-token-controller

        a. Add Request --> Name (Generate Access Token Using Refresh Token - If Access Token Is Expired)

        b. POST --> http://localhost:9080/oauth2/refresh --> Body --> raw
                {
                    "refreshToken": "{{refreshToken}}"
                }
        
        C. Store The token globally --> Scripts --> Post-response
            const responseBody = pm.response.json();
            pm.globals.set("accessToken", responseBody.accessToken);
            pm.globals.set("refreshToken", responseBody.refreshToken);
